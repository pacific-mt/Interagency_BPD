INTERGROWTH-21st International Fetal Growth Standards
How to read “Size-equivalent GA”
This is the gestational age at which the measured BPD or FL is closest to the INTERGROWTH-21st 50th-centile size. It describes fetal size, not the true gestational age, and should not be used to change an established gestational age or EDD.
Estimated centile is derived from the published INTERGROWTH-21st z-score reference values. The 10th–90th centile range is used for screening/triage. This tool is not a diagnostic tool.
